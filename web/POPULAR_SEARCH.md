# 실제 인기 검색어 연결 — 2026-10-29

- HomePage의 고정 예시 3개/예시 표기를 제거하고 `GET /api/search/popular`의 상위 3개로 대체한다.
- Enter(IME 조합 중 제외), 돋보기, 추천어 클릭 때만 `POST /api/search/events`를 추가 호출한다. 입력 중 기존 도우미 검색/필터는 그대로 유지한다.
- 기록용 UUID는 localStorage `pico.search.browser`에 저장한다. 서버는 날짜별 HMAC 해시로 바꾸며 실제 UUID를 저장하지 않는다. 저장 불가 환경은 페이지 수명 동안만 재사용한다.
- 순위는 홈페이지 진입과 1시간 주기로 조회한다. 실제 순위 집계는 백엔드가 KST 전날 기준 하루 1회 수행한다. AI는 별칭을 정리하고 순위는 중복 제거한 실제 검색 브라우저 수로 계산한다.
- 데이터 부족/기능 OFF/백엔드 미배포/오류면 칩을 숨긴다. 가짜 검색어를 대신 넣거나 기존 검색을 중단하지 않는다. 처음에는 최소 3개 브라우저에서 검색이 쌓이고 다음날 집계가 완료되어야 보인다.
- 공연명·도우미 활동명·예매처 이름을 모두 추천할 수 있지만, 칩 클릭 후 결과는 기존 도우미 프로필 문구 검색이다. KOPIS 공연 상세 검색으로 교체하지 않았다.
- 공연 배너, 거래/결제/로그인 등은 변경하지 않았다.
- 백엔드 V37 마이그레이션과 기능 활성화 설정이 필요하다. 프론트 환경/실제 .env/배포 설정은 변경하지 않았다.
- 검색 통계 수집/외부 AI 처리의 개인정보 안내는 운영자가 확인 후 활성화해야 한다. 브라우저 식별자는 사람이 서로 다름을 보증하지 않으며 고의 순위 조작을 완전히 방지하지 않는다.
- 테스트: `node scripts/test-popular-search.mjs`, 기존 `node scripts/test-kopis-banners.mjs`, `npm run build`.
