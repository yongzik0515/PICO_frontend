# 배너 이미지 넣는 곳

메인 화면 맨 위 티켓 캐러셀에 쓰는 사진을 이 폴더에 넣습니다.

## 파일 이름

`src/home/banners.ts`의 `image` 칸에 적힌 이름과 똑같이 저장해야 합니다. 지금은 `banner-1.jpg` ~ `banner-5.jpg` 5개를 씁니다.

## 권장 규격

- **가로 1400 × 세로 600px 안팎**(가로:세로 약 7:3). 카드에서 이미지는 메인 영역의 오른쪽 약 62%(데스크톱 약 560 × 300px)에 들어갑니다.
- 사진의 **오른쪽을 기준으로** 잘립니다. 중요한 피사체(얼굴 등)는 사진의 가운데~오른쪽에 두세요.
- 사진 왼쪽 40%는 카드 배경색으로 서서히 사라지므로, 왼쪽 끝에 글자·로고가 있어도 대부분 가려집니다.
- 세로로 긴 사진은 위아래가 많이 잘립니다. 가로 사진을 권장합니다.
- 파일 하나당 300KB 이하로 줄이면 첫 화면이 빨라집니다.
- 실제 서비스에 쓸 때는 초상권·저작권이 정리된 이미지만 쓰세요.

## 카드 배경색

`banners.ts`의 `color`를 비워 두면 사진 왼쪽 가장자리 색을 자동으로 뽑아 카드 배경으로 씁니다(흰 글자가 잘 보이도록 밝은 색은 조금 어둡게 맞춥니다). 원하는 색이 있으면 `color: '#1E5546'`처럼 직접 적으면 그 색을 씁니다.

## 파일이 없으면

이미지가 없어도 화면은 깨지지 않습니다. 대표 색상(없으면 `#2B2F6E`) 배경만 보입니다.
