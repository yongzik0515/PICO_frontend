## 보는 법

1. 주소를 열고 위쪽에서 페이지를 고르세요. **2차 시안 · 휴대폰**이 지금 안이고, **1차 시안**은 참고용이에요.
2. 파란 표시가 있는 보드는 재생(Play) 버튼으로 직접 눌러 볼 수 있어요.
3. 화면 안 버튼을 누르면 다음 보드로 넘어가요.
4. 함께 해 보기에서는 강조된 곳을 누르면 다음 단계로 넘어가요. 요청서나 최종 조건처럼 긴 화면은 끝까지 내리면 넘어가요.

## 2차 시안 · 휴대폰

| 번호 | 보드 | 파일 | 내용 |
|---|---|---|---|
| 1 | 메인 · 캐릭터가 한 번에 소개 | `M2-welcome-character` | 인사 → '좋아요' → 배너·검색·도우미 목록 라벨 → '마이' 누르기 |
| 2-1 | 마이 · 도우미로 바꾸기 | `M3-my` | 이용자 → 도우미 전환, '받은 요청' 탭 |
| 2-2 | 받은 요청 | `M4-leads` | 활동 켜기, 요청 열기 |
| 2-3 | 요청 상세 · 요청서 확인·수락 | `M5-detail` | 요청서 13개 항목 확인 → 요청 수락하기 → 확인 창 → 최종 조건 작성하기 |
| 2-4 | 조건 보내기 | `M7-terms` | 미리 채워진 최종 조건 확인 → 보내기 → '잠시 뒤' 카드 |
| 2-5 | 요청 상세 · 예매 착수 | `M8-start` | 확정된 조건 확인 → 예매 착수하기 → 확인 창 → 결과 등록 |
| 2-6 | 결과 등록·증빙 제출 | `M9-result` | 결과 고르기 → 결과별 화면 → 증빙 올리기 → 결과 등록 |
| 2-7 | 이런 경우도 있어요 · 소개만 | `M10-cases` | 부분 성공·실패·이의 제기 흐름 소개 |
| 3 | 혼자 해 보기 · 빈칸 · 강조 없음 | `M6-practice` | 메인부터 결과 등록까지 미션과 힌트만 보고 혼자 진행 |
| 4 | 도우미 신청 · 사전 신청 | `M11-apply` | 사전 신청 혜택, '사전 신청하고 회원가입하기' |
