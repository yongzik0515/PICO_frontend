# 도우미 사전 신청 · 온보딩 시안 안내

도우미가 될 사람에게 PICO 사용법을 미리 체험시키고, 마지막에 사전 신청(회원가입)으로 이어지는 페이지의 디자인 시안이에요.
실제 앱 화면을 가짜 데이터로 따라 하며 배우는 방식이고, 서버는 쓰지 않아요(실제 서버는 PG사 심사 중이에요).

## 1. 먼저 시안 보기

1. 캔버스 열기: https://claude.ai/artifact/XYREfkACTiUm6PvLK251zw
   - 비공개 캔버스라 시안 담당자가 공유해 줘야 열려요. 안 열리면 공유를 요청해 주세요.
2. 위쪽 페이지에서 **2차 시안 · 휴대폰**을 고르세요. 1차 시안은 참고용이에요.
3. 보드의 재생(Play) 버튼을 누르면 실제처럼 눌러 볼 수 있어요. 화면 안 버튼을 누르면 다음 보드로 이어져요.
4. 보는 순서: 1 메인 → 2-1 마이 → 2-2 받은 요청 → 2-3 요청 상세(요청서) → 2-4 조건 보내기 → 2-5 예매 착수 → 2-6 결과 등록 → 2-7 이런 경우도 있어요 → 3 혼자 해 보기 → 4 사전 신청

보드마다 무엇을 하는지는 [캔버스보기.md](캔버스보기.md)에, 지금까지 한 일은 [작업정리.md](작업정리.md)에 있어요.

## 2. 흐름 한눈에

| 구간 | 하는 일 |
|---|---|
| 메인 | 캐릭터가 인사하고, 배너·검색·도우미 목록을 한 번에 소개한 뒤 '마이'로 안내 |
| 함께 해 보기 | 강조된 곳과 말풍선을 따라 도우미로 바꾸기 → 요청 수락 → 조건 보내기 → 착수 → 결과 등록. 15단계이고 헤더 아래 막대로 진행을 보여 줘요 |

| 사전 신청 | 도우미 신청 화면에서 혜택을 보고 '사전 신청하고 회원가입하기' → 회원가입 |

| 항목 | 지금 상태 | 필요한 결정 |
|---|---|---|
| 사전 신청 혜택 | 예시 3개(매칭권 OO장 무료, 심사 먼저 진행, 오픈 후 OO일 목록 상단 노출) | 실제로 줄 혜택과 숫자 |
| 사전 신청 버튼 연결 | 시안에서는 안내 문구만 나와요 | 실제 회원가입(/signup)으로 보낼지, 별도 사전 신청 폼으로 받을지 |
| 배포 | 미정 | Vercel 팀 계정과 요금제(무료 Hobby는 비상업용으로 알고 있어 확인 필요), 쓸 도메인 |
| PC 화면 | 휴대폰 시안만 있어요 | PC에서는 휴대폰 틀을 가운데 띄울지, PC용을 따로 만들지 |

## 4. 실제 앱과 일부러 다른 부분

나머지 화면 구조와 문구는 `web/src` 화면 코드에 맞췄어요. 실제 앱 화면이 바뀌면 시안도 같이 고쳐야 해요.

- **결과 등록:** 실제 앱은 한 화면에서 결과를 고르면 아래 칸이 바뀌어요. 시안은 결과마다 다른 화면으로 넘어가요.
- **혼자 해 보기:** 실제 앱은 요청서 내용으로 칸이 미리 채워져요. 시안은 칸을 비워 두고 아무 내용이나 적게 했어요. 체험 흐름을 이어 가려고 직접 거래도 막아 두었어요.
- **화면 위쪽 알림(토스트):** 실제 앱에는 있지만 시안에서는 뺐어요.
- **체험용 연출:** '잠시 뒤 · 이용자가 확정하고 결제했어요' 카드와 '활동을 켜면 요청이 와요'는 실제 앱에 없어요.

2. Vercel에 연결해 브랜치마다 생기는 미리보기 주소로 검토하고, 하위 도메인을 연결해요.
3. 링크 미리보기(OG 태그), 채널별 UTM, 단계별 이탈을 볼 분석 이벤트(체험 시작, 함께 해 보기 완료, 혼자 해 보기 완료, 사전 신청 클릭)를 넣어요.
4. 사전 신청 버튼을 3번에서 정한 곳(회원가입 또는 폼)에 연결해요.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `design/project/` | 캔버스 원본(`.dc.html` 보드, `canvas.json`). 캔버스 전용 형식이라 브라우저에서 바로 열리지 않아요 |
| `design/build-*.cjs` | 보드를 만드는 스크립트. `build-guided`는 2-1·2-3·2-4·2-5·2-6, `build-practice`는 3, `build-apply`는 4를 만들어요. 나머지 보드는 직접 고친 파일이에요 |
| `design/holes.cjs`, `design/flow.cjs` | 검사 스크립트. 템플릿 값·태그 짝, 화면 이동과 단계를 확인해요 |

스크립트는 Node로 실행해요. 예: `node 사전신청/design/build-guided.cjs`, `node 사전신청/design/flow.cjs`.
캔버스에서 직접 고친 보드는 스크립트를 다시 돌리면 덮어써지니, 고친 내용을 스크립트에도 옮긴 뒤 실행해 주세요.
